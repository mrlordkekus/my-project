# Список: Word → Excel (Windows x64)

Готовая переносимая программа для Windows 10/11 x64. Работает без интернета, установки Python и Microsoft Office.

## Скачать

[Скачать ZIP программы (27,3 МБ)](./Spisok-Windows-x64.zip?raw=true)

## Запуск

1. Скачайте ZIP и распакуйте весь архив в обычную папку.
2. Откройте `Start.cmd`. Интерфейс откроется в браузере.
3. Загрузите Word `.docx`, выберите именительный (по умолчанию) или дательный падеж.
4. Проверьте и при необходимости исправьте таблицу, затем нажмите «Сохранить Excel».
5. Для завершения используйте кнопку «Завершить».

В Excel ровно 5 столбцов: звание, ФАМИЛИЯ, Имя, Отчество, Войсковая часть. Начальные нули номеров сохраняются.

Редкие, женские и нерусские ФИО обрабатываются локальными словарями. Неоднозначные формы отмечаются для ручной проверки: безошибочное восстановление любого ФИО из родительного падежа невозможно. Поддерживаются текст и таблицы `.docx`; старый `.doc` нужно пересохранить, сканы не распознаются.

Подробная инструкция — `README.md` внутри архива. `Check.cmd` проверяет встроенные зависимости и обработку тестовой записи.

Проверены 10 автоматических тестов и полный цикл в браузере под Linux. Запуск на настоящей Windows в среде разработки не проверялся.
